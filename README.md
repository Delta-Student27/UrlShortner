#  URL Shortener

A scalable URL Shortening service built using Spring Boot, React, and AWS, designed to generate short links and handle fast redirections with low latency.

---

##  Features

- Generate short URLs using unique hash-based encoding
- Fast and efficient redirection to original URLs
- RESTful API architecture using Spring Boot
- Responsive frontend built with React.js
- Containerized application using Docker
- Automated CI/CD pipeline using Jenkins
- Cloud deployment on AWS (EC2)

---

##  Tech Stack

**Frontend:**
- React.js
- Axios

**Backend:**
- Spring Boot
- REST APIs

**DevOps & Cloud:**
- Docker
- Jenkins (CI/CD)
- AWS EC2

**Database:**
- MySQL
